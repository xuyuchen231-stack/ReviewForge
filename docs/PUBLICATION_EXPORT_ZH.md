# 双栏、图件与实际引用顺序（2026-11-01）

## 修复的问题

源码中按首次引用排列，不能保证 PDF 的阅读顺序正确：浮动表格可能提前出现在页面上。此前的导出还会为解决溢出切换成整篇单栏。文献库中的同 DOI 不同键也可能让同一论文出现两次。

现在保留原稿与已经审查的候选，在单独导出层处理：

1. 只合并一个明确且无歧义的相同 DOI；不依据相似标题猜测，也不读取注释中的旧 DOI。映射写入报告。
2. 保留双栏正文，宽图表使用合法的跨栏浮动位置，避免底部专用位置阻塞整个图件队列。宽展示公式使用局部 strip，不改写公式；字体采用可移植的 Latin Modern，希腊正文符号处理保留公式、URL 和标识符。
3. 用 PDF 的实际坐标、双栏区域和跨栏标记核查首次引用次序。对合并数字区间补齐没有单独超链接的中间项。标记/编号映射缺失则显示未核实，不以缺失检查为通过。
4. 每次重编译前检查预算；失败时恢复源文件、PDF、编号辅助文件和构建报告。最终来源指纹取实际导出文件字节。
5. 项目提供经核对的图件计划时，以固定绘图程序生成来源关联的概念图，保留原图；没有图件计划时不伪造实验数据或统一套图。绘图和本次版式修复不调用模型。
6. 生成独立 Overleaf 工程：main.tex、引用到的图件/样式、所附公共样式的原始来源与说明。ZIP 不包含 API 密钥、无关论文或运行日志；使用 XeLaTeX，内嵌参考文献无需 BibTeX 步骤。

## 本机稿件验证

当前修正副本有 8 张图、3 张表，其中新增 4 张概念图，分别讨论学习接口、验证主张、尺度转移和不确定性。来源和图示性质写入图注与图件记录，没有新增虚构实验值。

六组相同 DOI 的重复引用键被合并，保留 86 个文献条目。PDF 中的首次引用顺序与编号一致；后文再次引用同一文献仍使用其旧编号，因此每一个括号的数字并不要求随全文一直增加。

两份实际工程（正文导出和独立 main.tex）均在本机 XeLaTeX 编译及排版检查通过。32 段展示公式的源码逐项相同；82 页未发现空白页、缺字、未定义引用或越出页面的字符。代表性双栏、图件和公式页面经过视觉检查；这不是整篇科学论述或投稿资格的认证。

此前 52/58 个单元通过模型审查的进度保持不变；版式和图件变化不把未解决科学问题改为已通过。Overleaf 工程已本机编译验证，没有伪称已登录云端编译或投稿。
