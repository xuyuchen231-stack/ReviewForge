# Scientific major-revision pipeline

## Goal
Repair evidence reliability and synthesis architecture before another whole-paper run. Preserve originals, accepted outputs, free-provider configuration and editable bilingual exports. Model review never implies expert/author approval.

## Decisions
- A canonical per-study fact registry is the shared truth; chapter-specific comparison axes are projections, not competing mutable facts.
- Current inspected source access overrides stale abstract metadata; partial excerpts never prove a paper did not report something.
- Quote verification and semantic review remain separate. Conflicting positive facts block acceptance; inaccessible/unknown observations cannot overwrite reported facts.
- Evidence synthesis uses operating-change type and prediction-time information boundary as primary axes. Microbial experiments, microbial simulations, adjacent-domain methods and reviews remain distinct.
- Whole-paper editorial completion and PDF compilation do not imply scientific readiness.
- Seven target sections, preserving analytical examples once; no invented experiments or numerical rankings.

## Tasks and verification
1. Source-access regression: add fault fixtures for old abstract labels plus acquired full text; fix source_packet and preserve source hashes/coverage.
2. study_registry.py: versioned source-bound field facts; immutable IDs, conflicts, subset digests, relevant-source cache invalidation. Test unknown-vs-reported precedence, contradictory facts, unchanged unrelated-study contracts and source quote/locator integrity.
3. Canonical extraction: common study card once per source version, with fixed required matrix fields. Feed current registry facts into planning, synthesis and editorial contexts; old per-unit snapshots cannot silently override new facts.
4. scientific_quality.py: complete study-level matrix exports, cited-claim inventory, exact passage/fact-bound semantic review, explicit uncovered claims, source-access denials and domain/outcome boundaries; report repetition/length and source-version readiness separately from technical build.
5. major_revision.py: seven-section rewrite contracts, shared fact/matrix input, scoped sources per section, bounded repair/review and resumable caches. Require evidence reconciliation and whole-paper semantic review before final scientific-ready status. Keep source full reference and current PDFs.
6. Verify the three reviewer examples against primary sources (Khambhawala, Luna, Pinto); install verified fact corrections locally without inventing unknown protocol details. Add technical issue checks for trajectory sensitivities and hard/projection/penalty conservation guarantees.
7. Run relevant offline/fault suites and a bounded affected route; independent code review; update local installed skill/docs and GitHub. Do not launch another expensive full manuscript run during this code-first request.

## Acceptance
Demonstrate current facts propagate to all consumers, conflicts cannot be hidden by a last-write-wins merge, >8 repeated citation claims have explicit coverage, final-edited manuscript hashes invalidate scientific review, matrix provenance is inspectable, adjacent-domain studies cannot pass as microbial experiments, and incomplete condensation cannot be labeled publication-ready. Report limitations honestly; no automated claim of scientific peer-review approval.

## Implemented and validation scope
- Added immutable source snapshots, DOI identity checks, current-access precedence, source-versioned canonical study cards, explicitly logged reconciliation and reviewed-fact eligibility.
- Added bounded public publisher-PDF acquisition through Crossref, including DOI/PDF-text validation and cached access failures; subscription access is not bypassed.
- Added long/wide provenance matrices, exact sentence-bound semantic review, same-study cross-section comparison, selective review caches and final delivery reporting/gates.
- Added resumable seven-section reconstruction, rejected-cache repair, one bounded whole-paper repair and existing bilingual export integration. Plain-text translation stays separate from structured scientific responses.
- Installed verified positive facts for the three reviewer examples in the local private workspace; original manuscripts and PDFs retained. ACS remains publisher-index excerpts, not claimed full text.
- Offline suites and actual local prepare/audit route are verified. No full model-driven manuscript rewrite was launched in this code-first task. Model passes and tests do not establish scientific adequacy or submission readiness; remaining evidence gaps must be reported by the next run.
