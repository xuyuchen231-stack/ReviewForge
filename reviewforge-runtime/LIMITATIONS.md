# Scope and implementation boundaries

The engine supports Markdown, user-supplied source excerpts, deterministic excerpt anchoring, model-assisted peer review, Git commits, checkpoint recovery, dual model routing and a nine-hour deadline. It does not fetch primary literature, guarantee scientific truth, edit complex LaTeX projects, or run while the Windows computer is asleep. Unattended operation may end before the deadline because of API limits or lack of accepted improvements. All API calls transmit manuscript and evidence text to the configured provider.
