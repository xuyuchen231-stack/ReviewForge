# Light-skills workflow reference

Source: https://github.com/Light0305/Light-skills (MIT; copyright 2026 Light0305).
The ReviewForge integration borrows workflow design from Light's `light-orchestrator`, `light-literature-search`, `light-citation`, `light-paper-writing`, `light-consistency`, `light-typesetting`, `light-figure`, `light-file-reading`, `light-memory-pm`, `light-review-rebuttal`, `light-research-ethics` and `light-venue-matching` skill guidance.

Three high-priority safeguards:

- Evidence tiers: bibliographic metadata cannot substantiate experimental results, validation or numerical comparisons. Require inspectable full-text excerpts, locator, and independent scholarly judgment for those claims.
- Audit handoffs: never mark citation, manuscript, visual or PDF checks as passed without executing each respective check. Tool absence is UNAVAILABLE, not PASS.
- User decisions: final journal choice, substantive research-direction changes, public release and master-file replacement belong to the author.

The local lightweight Runtime implements a selected subset. Do not assume interoperability with Light's native project passport, findings contracts, or every bundled script.
