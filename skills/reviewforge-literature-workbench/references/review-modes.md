# Review mode decision guide

## Narrative or critical review

Use when the goal is to explain a field, compare approaches, evaluate debates, or propose a conceptual framework. Search transparently across suitable sources and document search dates, axes, and limits. Do not require PRISMA flow counts unless the design actually uses systematic screening.

## Scoping review

Use when the purpose is to map concepts, methods, populations, evidence types, or coverage. Define the scope and charting fields before extraction. Select an applicable reporting framework and do not imply that a broad map estimates effects.

## Systematic review

Use when a focused question and explicit eligibility criteria support reproducible study selection. Document databases, complete search strings, dates, deduplication, screening decisions, full-text retrieval, exclusion reasons, and the appropriate reporting guidance. Do not fabricate screening counts or claim dual screening when it did not happen.

## Meta-analysis

Use only when outcomes, designs, and effect measures can be compared meaningfully. Verify each extracted value against the primary report, define transformations and models, assess heterogeneity and bias, and keep quantitative synthesis separate from narrative interpretation. Do not calculate pooled values from abstracts or review-level summaries unless the review protocol explicitly supports that data source.

## Cross-cutting safeguards

- A review type is a method choice, not a prestige label.
- Report the actual search and screening work performed.
- Do not force a quantitative consensus ratio onto heterogeneous evidence.
- Treat missing full text as a retrieval limitation, not as evidence that a study is ineligible.
