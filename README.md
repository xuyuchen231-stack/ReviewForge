# ReviewForge v4

A Windows-oriented research review writing workflow for bilingual English/Chinese LaTeX manuscripts.

## Project contents

- `reviewforge-runtime/`: local Python/Windows runtime, source verification, section-level editing, LaTeX/PDF compilation.
- `reviewforge/`: ChatGPT skill instructions and research-writing review guidance.

## Safety

Never commit `.env`, API keys, private manuscripts, local workspace outputs, or generated PDFs. Set credentials locally using `setup_secret.bat`.

## Research focus

Hybrid modeling of microbial fermentation: dynamic prediction under changing operating conditions. The target is a substantive bilingual two-column review with at least 60 *actually cited and verified* scholarly references.
